Bridges of time

Made with unity

A Small Game I submitted for a 2 day Game Jam for the GMTK Game jam 2026. In this Game you must guide your character (the square) to the portal at the end of the level. You must create a bridge by clicking the screen away from the player to dicate the length of the bridge. Keep going until you complete all the levels.

Creating this game taught me alot about Unitys Line renderer; Including how it behaves with colliders, Making multiple lines based on mouse position, and slope maths used to calculate the lines tilt against the players position

You can find my game here Bridges of time.

Frogger

Made in unity

In this project I made my own todolist application with python, using the tkinter module. This is a personal project I created to learn more about the tkinter module and its various features. The todolist allows the user to save their notes in a text document in the todolist directory. They can then open the text document and see their notes

Features

  • Text input feild
  • Colour picker for both the frame fill and the background
  • Basic file handling
  • Button to clear notes, clear last note, etc
  • Button to reset background
  • Button to clear text input

You can find this project on my github page
